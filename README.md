# 🔐 Python Password Generator

A simple and customizable command-line password generator built with Python. This tool allows users to generate secure passwords by specifying length and choosing whether to include uppercase letters, digits, and special characters.

## 📌 Features

- Choose custom password length
- Optional inclusion of:
  - Uppercase letters
  - Special characters (e.g., !@#$%^&*)
  - Digits (0–9)
- Ensures at least one character from each selected category
- Secure randomization for password strength

## 🚀 Getting Started

### Prerequisites

- Python 3.x  
  Download from: [https://www.python.org/downloads/](https://www.python.org/downloads/)

### How to Run

1. Clone the repository or download the script.
2. Open your terminal or command prompt.
3. Run the script with:

```bash
python password_generator.py
```

4. Follow the prompts:

```
Enter the desired password length: 12
Include uppercase letters? (yes/no): yes
Include special characters? (yes/no): yes
Include digits? (yes/no): yes
Generated password: 8z&WafpLq#1D
```
